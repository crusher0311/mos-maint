The enterprise tire DVI presentation is a fictional, browser-only product slice, not authorization for a production DVI rollout. Keep it separate from Shop Workflow branding work and the separate video-DVI implementation.

**Why:** The user explicitly scoped a presentation with no shared stores, live Protractor writes, AI processing, scanner controls or production login.

**How to apply:** Use manual wheel-specific measurements, technician-confirmed results and explicit simulated handoff. Always document completed green results along with concerns; battery pass/fail must remain manual with matching test standards. Do not boot the root production app for preview testing.
