application/json
responses
/
200
id
integer
Unique identifier of this record.

payment_id
integer or null
A foreign key which points to a Payment.id. Represents the final payment that is associated with this transaction which will appear on the RO and in reporting. It is only created for authorized transactions.

repair_order_id
integer
A foreign key which points to a RepairOrder.id. Represents the RO that this transaction was made against.

staff_id
integer
A foreign key which points to a Staff.id. Represents the staff member who attempted the transaction.

status
string
The current status of this transaction. One of 'approved', 'retry', 'declined', 'authentication_error', 'invalid_hsn', 'request_error', 'server_error', 'terminal_not_connected_error', 'terminal_in_use_error', 'transaction_cancelled_error', 'pin_debit_not_supported', 'decryption_failure', 'signature_not_supported'. Only 'approved' is a successful status, meaning that the payment transaction was authorized.

serial_number
string
The HSN of the credit card reader.

mid
string
The merchant ID that the transaction was made against.

requested_amount_cents
integer
The amount in cents that the user attempted to charge or refund.

amount_cents
integer
The amount that was actually charged or refunded.

reference_number
string
The unique reference number for this transaction.

account
string
An obfuscated account number of the payment card.

name
string
The name on the credit card.

currency
string
response_code
string
The raw gateway response code of the transaction.

response_text
string
A human readable description of the transaction status.

bin_type
string or null
entry_mode
