Create a recommendation
post
/api/v1/tenants/{tenant_id}/recommendations
Request
Path Parameters
tenant_id
integer
required
Examples:
1
Body

application/json

application/json
repair_order_id
integer
required
A foreign key which points to a RepairOrder.id. Represents the repair order related to this recommendation.

description
string or null
The title of the recommended service. Either this field or canned_job_id must be present. If canned_job_id is provided, this field will be ignored.

canned_job_id
integer or null
A foreign key which points to a CannedJob.id. Represents the canned job related to this recommendation. Either this field or description must be present.

201
successful
