Authentication
Credentials
All Shop-Ware API endpoints require client authorization. Every request must include the X-Api-Partner-Id and X-Api-Secret in the HTTP header. These credentials must be requested from Shop-Ware support.

Webhook requests may be authenticated by verifying the X-Api-Secret request header, which will be set to the client’s API secret.

All requests must be sent over HTTPS (TLS 1.2 or higher), and all webhooks will be sent over HTTPS. Please note, Shop-Ware certificates are frequently automatically rotated, please use standard certificate-chain validation techniques. See webhooks documentation for details.

We currently do not have the capability to whitelist specific IP addresses or clients.

Including invalid credentials, or failing to include any credentials will result in a 401 Unauthorized response. Attempting to access a tenant_id that has not been specifically granted will result in a 404 Not Found error response, regardless of whether the tenant actually exists. Sending a request with an HTTP verb other than GET for a tenant_id that has not specifically granted write access will result in a 403 Forbidden error response. It is possible to determine which tenants are currently accessible by querying /api/v1/tenants.

Authorization
Access to data for a given set of credentials is granted on a per-tenant basis. Access to any data will only be provided at the direct request of the controlling Shop-Ware tenant owner.

Public integrations
Shop-Ware Partner Integrators (third parties who integrate their product or service with Shop-Ware for the use of our mutual customers) may have their integration or service listed in the Shop-Ware settings page as a "Public Integration" following execution of a partnership agreement. Please contact support for details.

Private integrations
Integrations that are not intended to be used be individually granted by Shop-Ware Support at the request of an authorized representative of the tenant owner, which may or may not include write access (requests other than GET), at the specific request of the tenant owner.
