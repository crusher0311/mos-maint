Get a list of all inventory
get
/api/v1/tenants/{tenant_id}/inventories
Request
Path Parameters
tenant_id
integer
required
Examples:
1
Query Parameters
in_stock
any
Filter response to include only in stock inventories (min_stock > 0) if query parameter key is present.

Example:
true
on_hand
any
Filter response to include only on hand inventories (quantity_on_hand > 0) if query parameter key is present.

Example:
true
page
integer
Examples:
1
per_page
integer
Examples:
30
updated_after
string
Filter response to only include records updated after a given time

Examples:
2022-10-24T12%3A00%3A00%2B08%3A00
Responses
200
successful

application/json
