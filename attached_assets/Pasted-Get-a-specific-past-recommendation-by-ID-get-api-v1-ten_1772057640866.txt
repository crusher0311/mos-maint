Get a specific past recommendation by ID
get
/api/v1/tenants/{tenant_id}/past_recommendations/{id}
Request
Path Parameters
id
integer
required
Examples:
1
tenant_id
integer
required
Examples:
1
Responses
200
successful

Body

application/json

application/json
id
integer
Unique identifier of this record.

description
string
The title of the previously recommended service

approved
boolean
True if the past recommendation has since been approved by the customer, false if it has been declined, and null otherwise.

approver_id
integer or null
A foreign key that points to a Staff or Customer ID. This represents the person who approved the recommendation (if it has been approved, null otherwise).

approval_at
string<date-time> or null
Date and time the recommendation was approved if it has been approved, null otherwise.

approval_type
string or null
Type of approval: one of "customer" (Approved by customer), "email" (Approved by email), "estimate" (Approved in estimate), "person" (Approved in person), "phone" (Approved by phone). Null if unapproved or declined.

imported
boolean
True if the past recommendation has been added as a service on an Repair Order, false otherwise. All imported=true past recommendations will also be done=true, but not all done=true past recommendations will be imported=true.

vehicle_id
integer
A foreign key that points to a Vehicle ID. This represents the vehicle that this service was recommended for.

done
boolean
True if the past recommendation has been either sold to the customer, or has been manually marked as done by a staff member (for example, work since performed by another shop). These past recommendations will no longer be presented to the vehicle owner on future visits.

recommendation_id
integer
A foreign key which points to the Recommendation that was unsold at the time that the original source repair order was closed, resulting in the creation of this past recommendation.

created_at
string<date-time>
Date and time when record was created.

updated_at
string<date-time>
Date and time when record was last updated.
