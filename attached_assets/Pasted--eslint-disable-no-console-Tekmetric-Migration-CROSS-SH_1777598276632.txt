/*
 * Tekmetric Migration — CROSS-SHOP CLONE WITH CUSTOMER/VEHICLE OVERRIDES
 *
 * Purpose: clone one open RO from a SOURCE shop into a brand-new RO in a
 * DEST shop, attaching it to a customer + vehicle that already exist in
 * the dest shop (i.e. NOT recreating the source customer/vehicle in dest).
 *
 * Use case: you have an RO in shop A under customer Foo, and you want a
 * test copy of it in shop B under an existing customer Bar / vehicle Baz.
 *

 * Differences vs 04:
 *   - Source shop and dest shop are separate config knobs.
 *   - DEST_CUSTOMER_ID and DEST_VEHICLE_ID are required overrides

 *     switch shops via the dropdown. So this script needs TWO tokens —

 *   - Use 00-print-token.js to grab each token (it auto-copies to
 *     clipboard), then paste both into SOURCE_TOKEN / DEST_TOKEN below.
 *

 *   1. Find Jay Demore's customer ID in dest shop 14245 (URL ends in
 *      `/admin/shop/14245/customers/{customerId}`).
 *   2. From his customer page, click his vehicle (URL ends in
 *      `/vehicles/{vehicleId}`).

 *      `/repair-orders/{roId}/estimate`).
 *   4. On a SOURCE-shop tab (10214), paste 00-print-token.js into the
 *      DevTools Console — it copies that tab's token to your clipboard.
 *      Paste it into the SOURCE_TOKEN field below.
 *   5. Switch the tab to a DEST-shop URL (14245) and repeat — paste that
 *      token into DEST_TOKEN below.
 *   6. Fill in the CONFIG block (RO id, customer id, vehicle id, tokens).
 *   7. Open DevTools Console on ANY Tekmetric tab (either shop is fine
 *      — every fetch picks the right token from the config).
 *   8. Paste the whole file. With CONFIRM=false (default) it pre-flights
 *      both shops + validates dest customer/vehicle + prints what it
 *      would do, with no writes.
 *   9. If the dry-run looks right, flip CONFIRM=true at the top, re-paste.
 *      The new RO is created in dest shop with the override

  async function jsonFetch(path, opts = {}) {

      method: opts.method || 'GET',
      credentials: 'include',

        'Content-Type': 'application/json',
