Get a list of all shops
get
/api/v1/tenants/{tenant_id}/shops
Request
Path Parameters
tenant_id
integer
required
Examples:
1
Query Parameters
page
integer
Examples:
1
per_page
integer
Examples:
30
updated_after
string
Filter response to only include records updated after a given time

Examples:
2022-10-24T12%3A00%3A00%2B08%3A00
Responses
200
successful

Body

application/json

application/json
responses
/
200
results
array[object]
id
integer
Unique identifier of this record.

identifier
string
A name used to uniquely identify a shop.

name
string
Shop`s name.

address
string
Shop`s address.

phone
string
Shop`s phone.

live_at
string<date-time>
The datetime the Shop went live.

time_zone
string
Shop`s timezone

service_desk_email
string
Shop`s service desk email.

avg_labor_cost_cents
number
Average labor cost cents. It used to estimate Labor GP % and GP/hr on unassigned labor lines or for technicians that don’t have a pay structure set up.

number
Part tax rate.

labor_tax_rate
number
Labor tax rate.

hazmat_tax_rate
number
Hazmat tax rate.

supply_fee_rate
number

part_supply_fee_rate
number
Supply fee rate for parts.

supply_fee_name

Supply fee name.

sublet_tax_rate
number
Supply tax rate.

string<date-time>
Date and time when record was created.
