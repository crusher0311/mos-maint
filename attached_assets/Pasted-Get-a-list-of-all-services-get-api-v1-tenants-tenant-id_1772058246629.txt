Get a list of all services
get
/api/v1/tenants/{tenant_id}/services
Request
Path Parameters
tenant_id
integer
required
Examples:
1
Query Parameters
repair_order_id
integer
A foreign key which points to a WorkOrder.id. Represents the repair order related with this service.

Examples:
null
technician_id
integer
Filter response to only include Services with labors assigned to this Technican ID.

Examples:
null
updated_after
string
Filter response to only include Services updated after a given time

Examples:
2026-05-17T12:14:56Z
Responses
200
successful

Body

application/json

integer
Unique identifier of this record.

title
string
The title of the service.

completed
boolean
True if the service has been completed.

category_id
integer or null
A foreign key that points to a Category ID.

canned_job_id
integer or null
A reference that points to a CannedJob ID.

labor_rate_cents
integer or null
The rate in cents that labor on this service is charged at.

fixed_price_cents
integer or null
The price in cents that this service will be charged at.

fixed_price_labor_total_cents
integer or null
The total price in cents that labors on this service will be charged at.

is_fixed_price_service
boolean
Determines if this service has a fixed price.

comment
any
Service comments.

The datetime the service was last marked completed. This may occur if the service had been marked completed then restarted and marked completed again.
