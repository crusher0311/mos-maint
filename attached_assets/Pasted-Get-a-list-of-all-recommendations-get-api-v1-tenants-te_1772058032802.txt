Get a list of all recommendations
get
/api/v1/tenants/{tenant_id}/recommendations
Request
Path Parameters
tenant_id
integer
required
Examples:
1
Query Parameters
page
integer
Examples:
1
per_page
integer
Examples:
30
updated_after
string
Filter response to only include records updated after a given time

Examples:
2022-10-24T12%3A00%3A00%2B08%3A00
Responses
200
successful

Body

application/json

application/json
results
array[object]
id
integer
Unique identifier of this record.

description
string or null
The title of the recommended service

approved
string or null
"true" if the recommendation has been approved by the customer, "false" if it has been declined, and null otherwise.

approver_id
integer or null
A foreign key that points to a Staff or Customer ID. This represents the person who approved the recommendation (if it has been approved, null otherwise).

approval_type
string or null
Type of approval: One of "customer", "email", "person", and "phone". Null if unapproved or declined.

imported
boolean
True if the recommendation has been added as a service on a Repair Order, false otherwise.

quick_price_cents
number or null
Quick price in cents

service
object
repair_order_id
integer
A foreign key that points to the RepairOrder that this Recommendation belongs to

approval_at
string<date-time> or null
Date the recommendation was approved if it has been approved, null otherwise.

integrator_tags
array[object]
created_at
string<date-time>
Date and time when record was created.

updated_at
string<date-time>
Date and time when record was last updated.

limit
integer
limited
boolean
total_count
integer
current_page
integer
total_pages
integer
