Canned Jobs
Returns a list of all canned jobs filtered by the provided search parameters.
Request Headers
Authorization	Bearer access_token
Request Parameters
shop
Integer	Filter by shop ID
search
String	Filter by job name
categories
Array<String>	Filter results by job category codes
Permitted Values: [ Unassigned - (Filter jobs with no categories), Category Code - (Filter with job category code) ]
rates
Array<String>	Filter results by labor rates
Permitted Values: [ None - (Filter jobs with no labor), Labor rate in cents, i.e. 7250 - (Filter with labor rate) ]
sort
String	Specify the property you'd like to sort on
Permitted Values: [ jobCategory ]
sortDirection
String	Determine the direction you want to sort your results
Permitted Values: [ ASC, DESC ]
size
Integer	Specify the number of results you would like returned. The maximum page size is 100. For values greater than this value, the API overrides and returns 100 records. You can use pagination to access the next records.
page
Integer	Specify the page of results you would like returned
Response Attributes
id
Canned job id
name
Canned job name
note
Notes on canned job
jobTemplateType
Canned job template type
jobCategoryCode
Canned job category code
totalCost
Total cost of job in cents
laborRates
List of unique labor rates for job
labor
List of labor
parts
List of parts
discounts
List of discounts
fees
List of fees
GET
/api/v1/canned-jobs
Example Request
curl -X GET 'https://sandbox.tekmetric.com/api/v1/canned-jobs?shop=1' \
-H "Authorization: Bearer dd824dda-c02c-478a-aa84-cd9fdb217c15"

Add Canned Jobs To Repair Order
Adds given canned jobs to repair order
Request Headers
Content-Type	application/json
Authorization	Bearer access_token
Request Parameters
id
Integer	repairOrderId
Request Attributes


required	List of canned job ids

Response Attributes
data
List of created job ids
POST
/api/v1/repair-orders/{id}/canned-jobs
Example Request
curl -X POST 'https://sandbox.tekmetric.com/api/v1/repair-orders/1/canned-jobs' \
-H "Authorization: Bearer dd824dda-c02c-478a-aa84-cd9fdb217c15" \
-H "Content-Type: application/json" \
--data-raw '[609801]'
Example Response
{
  "type": "SUCCESS",
  "message": "Job(s) saved",
  "data": {
    "jobs": [
      1089313
    ]
  }
}
