Share Link to Repair Order
Allows a repair order to be shared for an estimate, invoice, or inspection.
Request Headers
Content-Type	application/json
Authorization	Bearer access_token
Request Parameters
id
Integer	repairOrderId
Request Attributes
shareDate
Date
required	Share date of item

shareItem
String
required	Type of Repair Order item to share
Permitted Values: [ ESTIMATE, INSPECTION, INVOICE ]
Response Attributes
data
Repair Order
PATCH
/api/v1/repair-orders/{id}/share-link
Example Request
curl -X POST 'https://sandbox.tekmetric.com/api/v1/repair-orders/1/share-link' \
-H "Authorization: Bearer dd824dda-c02c-478a-aa84-cd9fdb217c15" \
-H "Content-Type: application/json" \
--data-raw '{"shareItem":"ESTIMATE","shareDate":"2025-12-10T20:45:41.601Z"}'
