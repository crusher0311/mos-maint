Get a list of all purchase records
get
/api/v1/tenants/{tenant_id}/purchase_records
Request
Path Parameters
tenant_id
integer
required
Examples:
1
Query Parameters
page
integer
Examples:
1
per_page
integer
Examples:
30
updated_after
string
Filter response to only include records updated after a given time

Examples:
2022-10-24T12%3A00%3A00%2B08%3A00
Responses
200
successful

Body

application/json

application/json
results
array[object]
id
integer
Unique identifier of this record.

shop_id
integer
A foreign key that points to a Shop.id. Represents the shop in which the order was created.

invoice_number
string
A string which identifies invoice from provider.

purchase_order_number
string
A string which identifies purchase order from provider.

vendor_id
integer
A foreign key which points to a Vendor.id. Represents a vendor associated with this purchase record.

payment_type
string
The form of payment that was used to pay for these parts.

ecomm_integrator_order_id
integer
An identifier assigned to this order by the parts eComm integrator (if any).

is_return
boolean
True if this Purchase Record is a return.

line_items
array[object]
integrator_tags
array[object]
created_at
string<date-time>
Date and time when record was created.

updated_at

Date and time when record was last updated.

limit
integer
limited
boolean
total_count
integer
current_page
integer
total_pages
integer
