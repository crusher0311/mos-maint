Returns a list of all repair orders filtered by the provided search parameters.
Request Headers
Authorization	Bearer access_token
Request Parameters
shop
Integer	Search for repair orders by shop
start
Date	Specify a start Date to filter by Repair Orders created after the entered value
end
Date	Specify a end Date to filter by Repair Orders created before the entered value
postedDateStart
Date	Filter by repair order posted date
postedDateEnd
Date	Filter by repair order posted date
updatedDateStart
Date	Filter by repair order updated date
updatedDateEnd
Date	Filter by repair order updated date
deletedDateStart
Date	Filter by repair order deleted date
deletedDateEnd
Date	Filter by repair order deleted date
repairOrderNumber
Integer	Specify a specific RO# you want returned
repairOrderStatusId
Array<Integer>	Specify a status if you want to filter results to a specific status
Permitted Values: [ 1 - (Estimate), 2 - (Work-in-Progress), 3 - (Complete), 4 - (Saved for Later), 5 - (Posted), 6 - (Accounts Receivable), 7 - (Deleted) ]
customerId
Integer	Specify this value to get repairs for a specific customer
vehicleId
Integer	Specify this value to get repairs for a specific vehicle
search
String	Search for repair orders by RO #, customer name, and vehicle info
sort
String	Specify the property you'd like to sort on
Permitted Values: [ createdDate, repairOrderNumber, customer.firstName, customer.lastName ]
sortDirection
String	Determine the direction you want to sort your results
Permitted Values: [ ASC, DESC ]
size
Integer	Specify the number of results you would like returned. The maximum page size is 100. For values greater than this value, the API overrides and returns 100 records. You can use pagination to access the next records.
page
Integer	Specify the page of results you would like returned
Response Attributes
repairOrderNumber
Repair Order identifier per Shop
laborSales
Total labor sales in cents. Taxes and discounts not included.
partsSales
Total parts sales in cents. Taxes and discounts not included.
subletSales
Total sublet sales in cents. Taxes and discounts not included.
feeTotal
Total fees in cents. Taxes and discounts not included.
discountTotal
Total discounts in cents.
amountPaid
Total amount paid by customer.
