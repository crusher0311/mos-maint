Job
Returns a Job by ID
Request Headers
Authorization	Bearer access_token
Request Parameters
id
Integer	job ID
GET
/api/v1/jobs/{id}
Example Request
curl -X GET 'https://sandbox.tekmetric.com/api/v1/jobs/1084138' \
-H "Authorization: Bearer dd824dda-c02c-478a-aa84-cd9fdb217c15"
