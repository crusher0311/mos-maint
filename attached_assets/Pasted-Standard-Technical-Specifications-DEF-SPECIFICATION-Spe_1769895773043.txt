Standard Technical Specifications

DEF_SPECIFICATION

Specifications are generally numeric measures of a vehicle's dimensions, weights, capacities, and performance characteristics.

Field	Type	Description
specification_id	int	Primary Key
specification_category	varchar(32)	Specification Category. Can be used as a means of grouping specifications.
specification_name	varchar(32)	Name of specification (e.g. Length, Curb Weight)
specification_value	varchar(32)	Value of specification (e.g. 214.70, 4250)
is_ancillary	enum('Y','N')	When 'Y', please note that coverage will be limited. May not be provided for all Makes/Models


LKP_VEH_STANDARD_SPECIFICATION

Links vehicle_id from VEH_TRIM_STYLES or VIN_REFERENCE to its standard specification values.

Field	Type	Description
veh_specification_id	int	Primary Key for lookup table
vehicle_id	int	From VEH_TRIM_STYLES or VIN_REFERENCE
specification_id	int	From DEF_SPECIFICATION
